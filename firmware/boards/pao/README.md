# PAO 项目板

ESP32-S3，默认 16 MB Flash、八线 PSRAM。使用 Wi-Fi、I2S 数字麦克风
（如 INMP441）、I2S 功放（如 MAX98357A）、BOOT 按键、WS2812 状态灯、MX1508 双路电机驱动
和一块 3.3V 单路继电器组成的发射控制，以及 SSD1306 128×64 I2C OLED、3.3V 版 HC-SR04 超声波模块。
不需要摄像头或独立音频 Codec。

GPIO 按[硬件接线图](../../../hardware/README.md)配置，具体定义在本目录 `config.h`：

| 模块 | 信号 | GPIO |
| --- | --- | --- |
| I2S 麦克风 | WS / SCK / DIN | 4 / 5 / 6 |
| I2S 功放 | DIN / BCLK / LRC | 7 / 15 / 16 |
| BOOT 按键 | 低电平按下 | 0 |
| WS2812 状态灯 | 数据 | 48 |
| SSD1306 OLED | SDA / SCL | 41 / 42 |
| HC-SR04（3.3V 版） | Trig / Echo | 8 / 9 |
| MX1508 右电机 | IN1 / IN2 | 11 / 12 |
| MX1508 左电机 | IN3 / IN4 | 13 / 14 |
| 继电器 发射 | 低电平吸合 | 18 |

麦克风采样率 16 kHz，扬声器播放采样率 24 kHz。BOOT 单击切换对话，
启动阶段单击进入配网；没有保存的网络时沿用小智配网流程。
唤醒词为“小炮小炮”，也可按键启动对话。乐鑫没有该词的预训练 WakeNet 模型，
固件用 MultiNet（`mn7_cn`）把它作为命令词识别，配置在 `firmware/sdkconfig.defaults`：
`CONFIG_CUSTOM_WAKE_WORD` 为空格分隔的拼音，`CONFIG_CUSTOM_WAKE_WORD_THRESHOLD`（1–99，越小越灵敏）
用于调节误唤醒和漏唤醒，需实机测试后确定。
MultiNet 计算量是 WakeNet 的数倍，固件只在 VAD 判定为语音及其后 1 s 内运行识别，
唤醒词中间的停顿不会打断识别；环境噪声持续触发 VAD 时 CPU 占用会回升。
设备说话或聆听时再次说唤醒词会打断当前回复并重新开始聆听。
直接说话打断需要回声消除，板上 I2S 没有扬声器回采通道，暂不支持。
板型和构建配置名称均为 `pao`，
不复用上游参考板的 OTA 标识。

OLED 的 VCC 接 3V3、GND 接系统地，按模块 SDA/SCL 丝印连接；模块应带 I2C 上拉。
默认地址为 `0x3C`，总线速率 400 kHz。地址、分辨率和显示镜像设置集中在 `config.h`，
若实物地址为 `0x3D` 或画面方向不符，修改对应配置后重新编译。
GPIO41/42 用于屏幕后占用外部 JTAG 引脚，USB GPIO19/20 保留。

HC-SR04 的 VCC 接主控 3V3，GND 接系统地，Trig/Echo 分别接 GPIO8/9。
板级创建 `HcSr04` 实例，初始化后 Trig 保持低电平，调用 `readDistanceCm()` 才触发测量。
仅使用支持 3.3V 供电及信号电平的版本；驱动接口及错误处理见[固件说明](../../README.md#超声波测距)。
测距通过 `self.ultrasonic.get_distance` 暴露给灵矽；`self.chassis.move_forward` 使用距离反馈前进，
`self.chassis.move_to_distance` 前进到距障碍物的目标距离。
测距任务在后台持续采样，前方距离不大于可配置的警报触发距离时自动播放报警音；方向遥控本身不自动避障。

屏幕复用小智 OLED 界面，显示设备状态、表情和对话。启动时探测屏幕；
未连接或驱动初始化失败时记录日志、释放已申请的显示资源，并继续以无屏模式运行。
接入后运行期间拔除屏幕不支持自动恢复，需重新连接后重启。

板级初始化创建左右 `Motor`，再创建 `Chassis`，上电保持两轮停止；
随后创建 `Launcher`，上电保持两路继电器断开。
左轮按 `IN4/IN3` 顺序创建 `Motor`，反转左侧安装极性，使两轮正速度均表示车体前进；
右轮仍按 `IN1/IN2` 顺序。更换电机或接线后需重新核对方向。
底盘内部提供前进、后退、左转、右转、常规停止和立即停止六个无参数动作；
常规停止按输出渐变时间减速，立即停止直接清零两轮输出。
前进和旋转的最大输出属于可动态调整的 `ChassisConfig`。
按厘米前进由独立的 `ForwardDistanceMover` 组合前向超声波与底盘实现，不提供按厘米后退。
底盘通过小智的设备 MCP 协议向灵矽暴露以下工具，联网激活后随设备工具列表上报：

- `self.chassis.control`：`action` 必填，只接受 `forward`（前进）、`backward`（后退）、
  `turn_left`（逆时针左转）、`turn_right`（顺时针右转）、`stop`（按渐变时间减速）、
  `emergency_stop`（立即清零）六种值。四个方向动作使用设备保存的相应最大输出，
  可传 `duration_ms`，范围 `[100, 15000]`，默认 1000 毫秒，到时立即清零输出；
  两种停止动作忽略该参数。新指令替换当前运动及计时，并取消自动探索和待执行的动作序列；
  探索期间的 `stop` 也会立即清零输出。
- `self.sequence.run`：`steps` 为必填字符串，格式是逗号分隔的 `action:duration_ms`，不能有空格。
  `action` 支持 `forward`、`backward`、`turn_left`、`turn_right` 和 `fire`；前四个动作的
  `duration_ms` 为 `[100, 15000]`，`fire` 必须写 `300`，对应现有 300ms 发射脉冲。
  最多 20 步，总时长不超过 60000ms。例如
  `forward:1000,turn_left:800,fire:300` 表示前进 1 秒、左转 0.8 秒、再发射一次。
  固件按顺序执行，前一步结束才执行下一步，全部结束后自动停车；新的底盘控制、手动遥控、
  `stop`、`emergency_stop`、网页停止、Wi-Fi 断开或新的序列都会立即停车、取消整个待执行序列，
  不补跑后续步骤。
  参数错误或超限时返回错误且不启动；正在进行的 300ms 发射脉冲会先完成。
- `self.chassis.move_forward`：`distance_cm` 为必填整数 `[1, 390]`，使用设备保存的前进最大输出。
  起步前读取前方距离，以起始距离减去持续测得的距离估算已前进的厘米数，
  达到目标后停止。目标位置须与反射物相隔至少 10cm，否则返回错误且不启动。
  必须朝向同一静止、稳定反射物；空旷环境或移动目标不能用于此种距离估算，它不是轮式里程计。
  运动在独立任务中执行，工具返回“已开始”而非“已完成”。最多执行 15 秒，超时、测距失败或前方
  距离降至 10cm 时停止。其他底盘工具或手动遥控指令会取消该运动及待执行动作序列。
  例如“前进 20 厘米”调用 `{"distance_cm":20}`，随后可用下面的测距工具查询完成情况。
- `self.chassis.move_to_distance`：`distance_cm` 为必填整数 `[10, 390]`，表示停车后与前方障碍物
  保留的距离，使用设备保存的前进最大输出。起步前读取当前距离；已经达到或近于目标距离时不启动，
  低于 10cm 的目标直接拒绝。持续测距直到当前距离不大于目标值后停车；测距失败、意外进入 10cm 内
  或超过 15 秒时停止。调用该工具会取消待执行动作序列；只能向前，必须有同一静止、稳定反射物。
  例如“前进到离障碍物 20 厘米”调用 `{"distance_cm":20}`，随后可用下面的测距工具查询当前距离与状态。
- `self.ultrasonic.get_distance`：无参数，返回本次 `distance_cm`、`error` 及最近一次按距离运动的
  `requested_cm`、`moved_cm`、`motion_status`。测距失败时距离为 `null`，错误为 ESP-IDF 错误名称。
  状态为 `idle`（无运动）、`moving`（执行中）、`reached`（达到目标）、`obstacle`（空间不足）、
  `sensor_error`（测距失败）、`timeout`（达到 15 秒上限）或 `cancelled`（被其他指令中断）。
  `requested_cm` 对 `move_forward` 表示计划前进量，对 `move_to_distance` 表示目标障碍物间距；
  `moved_cm` 是实际距离变化估计值，可因目标变化而为负。只有 `reached` 表示按测距反馈达到目标。
- `self.chassis.explore_start`：无参数，进入自动探索。固件每次确认前方空间后短时前进，停车并原地转向，
  再测距决定下一步。前方距离不大于 35cm 时立即停车，连续两次测得至少 45cm 才开始前进；
  单段前进最长 3 秒，每次旋转约 1 秒，最多连续尝试 6 次转向，单次探索最多 2 分钟。
  距离小于 20cm 时不继续旋转，进入故障停车，需人工处理。
  前进和旋转持续输出上限为 50%，不改设备保存的手动运动配置。最小有效输出须低于 50%，左右轮比例不能为零。
  启动会取消当前运动或动作序列；返回“已开始”不表示前方已经可通行。
- `self.chassis.explore_stop`：无参数，立即停车并退出探索；`self.chassis.explore_status`：无参数，
  返回 `active`、`state`、`reason` 和 `turn_attempts`。`state` 为 `idle`、`checking`、`forward`、
  `settling`、`turning`、`recovering`、`searching` 或 `fault`；故障原因包括测距硬件错误、无通路、达到运行上限及运动看门狗超时。
  探索中短暂无回波时，仅在最近 200ms 内曾测得安全距离且该段运动未超时的情况下保持当前动作；
  持续无回波先停车。约 2 秒仍无回波、且曾测得至少 20cm 的旋转余量时，分段原地旋转并继续测距；
  从未测得有效距离或最近距离过近时保持停车等待。恢复有效读数后重新确认前方空间；
  总运行时间仍限 2 分钟，不能把持续无回波当作通路。手动底盘指令、发射、待机及 Wi-Fi 断开会退出探索。

例如“前进一秒”对应 `self.chassis.control` 参数
`{"action":"forward","duration_ms":1000}`；“向右转圈”使用 `turn_right`，
“停止”使用 `stop`，“立即停下”使用 `emergency_stop`。
运动输出和校准参数通过网页设置，不提供 MCP 参数配置工具。
参数由 MCP 层校验，超出范围或缺少必填参数时返回错误，不执行运动。
输出量是占空比，不能据此承诺实际速度、距离、旋转角度或严格直线。
按距离运动同样受采样间隔、超声波反射和停车惯性影响，停止后仍可能滑行，不能承诺厘米级精度；
需在实车上校准合适的占空比与停车余量。
探索使用单个前向传感器和定时转向，只能反应式漫游，不能感知侧后方、测量真实转角或建图；
35cm 停车距离和 50% 输出上限仍需实车测量速度与惯性后确认。短双音提示只在探索开始和转向时尝试播放，
语音聆听或播放期间跳过，避免遮挡退出指令。

发射器经设备 MCP 协议暴露 `self.launcher.fire`：无参数，继电器吸合 300 毫秒按下发射按钮后返回 `true`。
连续开多炮时多次调用该工具；单独调用会取消待执行动作序列和自动探索，但不会主动停止普通底盘动作。

`self.network.get_access_info` 无参数，查询当前 IP 地址和后台访问地址 `http://<设备 IP>/`。
用户问“你的 IP 是多少”“后台地址是什么”“怎么打开遥控页面”时调用，回复包含 IP 和完整地址；
后台需在同一局域网内访问。未连接 Wi-Fi 或后台未启动时返回错误。

`self.standby` 无参数，用于“退下吧”“待机”等结束对话的说法：等当前回复播完后关闭对话回到待机，
服务端 3 s 内没有回复时直接关闭，回复超过 20 s 时打断。它会退出自动探索，不停止普通底盘运动。

## 网页遥控

联网后设备在 80 端口提供遥控页，串口日志会打印 `Control page: http://<设备 IP>/`，
同一局域网内用浏览器打开即可。四个方向按钮分别控制前进、后退和两种原地旋转；
按住期间每 150 ms 续发一次 400 ms 的动作指令，松开时平滑停车。中央停止键立即清零输出；
失焦、页面关闭或断网后停止续发，超时保护在当前指令有效期结束时清零。
网页成功发起方向、定距或自动探索运动时，若设备仍在待机，会像短按机身按键一样进入在线语音聆听；
停车和修改配置不会唤醒，也不会自动让已唤醒的设备回到待机。
也支持 WASD / 方向键，最近按下且仍按住的方向优先。续发指令不会重置加速过程，
切换方向时底盘先降至零再升至新目标。
开炮键或空格键按一次发射一次。
网页和语音发射共用约 280ms 的“biu”电子音效，由板子扬声器播放并跟随设备音量；
若正在播放语音，音效会按现有音频队列顺序播放。音效来源与重新生成命令见[音效说明](../../components/pao/sounds/README.md)。
底盘区域每秒自动刷新前方障碍物距离，单位厘米；测距超时、传感器错误或断网时显示错误，不保留旧读数。
页面通过同源 `/ws` WebSocket 连接发送运动和配置指令，并每秒读取前方距离与探索状态。
连接断开或请求超过 3 秒未响应时清除按键状态，自动重连，不重放之前的运动指令；
板上时长限制继续生效。方向遥控、定距运动和停止指令会取消待执行的动作序列；
Wi-Fi 断开时设备立即停车并取消序列。

固件后台任务约每 100ms 采样一次前方距离；不大于警报触发距离时立即播放约 750ms 的短促报警音，
持续过近期间每 1.5 秒重播一次，距离超过触发距离 2cm 后解除报警。
遥控页“测距警报”滑块可将触发距离设为 2～100cm，默认 10cm；调节结束后保存到 NVS，重启后恢复。
设备正在聆听或播放语音、提示音时不会把报警音排队，待设备空闲后的下一轮检测再重试，
因此报警可能晚于障碍物进入触发距离的时刻。

页面底部的“运动设置”集中提供最大输出、输出渐变、最小有效输出、起步脉冲及左右轮比例。
前进／后退和旋转各有独立的最大输出滑块，范围均为 20%～100%，默认 80%；
它们用于网页、WebSocket 和语音动作。
两个值在调节结束后保存到 NVS，页面打开和设备重启后恢复。
底盘内部按实际时间渐变输出，
渐变时间范围 0～3 s，默认 1 s；0 表示直接达到目标。
最小有效输出范围为 0%～99%，默认 0%，且必须低于前进和旋转的最大输出；
非零时跳过低占空比区间再渐变，常规停止渐变回阈值后归零，立即停止直接清零。
每个轮子从静止起步时短暂输出至少为所设起步占空比、持续约 80ms，随后恢复配置的输出；
起步占空比范围 0%～100%，默认 70%，0 表示关闭脉冲。
停止、换向和修改运动配置会取消尚未结束的起步脉冲。自动探索起步也使用该脉冲，
因此起步瞬间可能超过探索模式的 50% 持续输出上限。
左右轮比例均在 0～1 之间，默认 1，仅降低相应侧输出；改变比例时也平滑过渡。
这些校准参数可在网页运行时调整，每次调节结束后保存到 NVS，设备重启后恢复；
页面打开时读取设备当前值，保存失败会提示重试。开环控制不能保证两轮实际转速相等，
应在实车上调整比例；某轮最大输出被比例降至阈值以下时，仍可能无法克服起步阻力。
设备可加载数值有效的当前及上一版运动配置；上一版配置的起步脉冲使用默认 70%。其他格式使用默认值，可在网页重新设置。

WebSocket 请求格式为 `{"id":1,"path":"/api/distance","query":""}`，`id` 为正整数，
`query` 使用 URL 查询串格式。响应为 `{"id":1,"ok":true,"data":...}`；失败时 `ok` 为 `false`，
`error` 包含错误原因。`path` 使用下列指令路径，控制成功时 `data` 为 `true`；配置和距离返回对应 JSON 对象。
请求仅支持不超过 512 字节的完整文本帧；无效格式会关闭连接。构建启用 `CONFIG_HTTPD_WS_SUPPORT=y`；
握手校验还要求启用 `CONFIG_HTTPD_WS_PRE_HANDSHAKE_CB_SUPPORT=y`，用于在升级前检查 Host、Origin 和单控制者。
已有构建目录若关闭了这些选项，需重新生成或通过 ESP-IDF 配置界面启用后重新编译。

遥控页、模拟器和验收脚本均通过 WebSocket 调用以下指令；参数放在 `query` 中，
取值错误返回 `ok: false`：

- `/api/chassis`，`query` 为 `action=&duration_ms=`：`action` 为上述六种值之一，四个方向动作的
  `duration_ms` 可省略，默认 1000 毫秒；`stop` 为平滑停车，`emergency_stop` 为立即停车。
- `/api/move_forward`，`query` 为 `distance_cm=`：与按厘米运动工具共用控制逻辑，默认 20cm；
  参数错误、起始测距失败或空间不足返回 `ok: false`，接受运动返回 `data: true`。
  方向动作和定距前进都使用设备保存的对应最大输出。
- `/api/move_to_distance`，`query` 为 `distance_cm=`：与目标障碍物间距工具共用控制逻辑，默认 20cm；
  参数错误、起始测距失败、已处于目标距离内或目标低于 10cm 时返回 `ok: false`。
- `/api/distance`：与测距工具共用结果格式，包含测距值、错误和最近一次按距离运动的状态。
- `/api/explore/start`、`/api/explore/stop`：与语音探索工具共用启停逻辑，控制成功返回 `data: true`；
  `/api/explore/status` 返回探索状态对象。中央急停按钮和方向遥控也会退出探索。
- `/api/launcher/fire`：发射一次，无参数。
- `/api/motion-config`，`query` 为空时读取配置，返回 `ramp_time_ms`、`left_scale`、`right_scale`、
  `move_output`、`rotate_output`、`min_output`、`start_boost_output`。
- `/api/motion-config`，`query` 为 `ramp_time_ms=&left_scale=&right_scale=&move_output=&rotate_output=&min_output=&start_boost_output=` 时校验并保存配置；
  `move_output`、`rotate_output`、`min_output` 和 `start_boost_output` 可省略，此时保持设备当前值，
  NVS 提交成功后生效，保存失败返回 `ok: false`。

HTTP 提供 `GET /` 加载页面，`/ws` 用于升级 WebSocket 连接。
`/ws` 同一时间只允许一个活动控制连接：第一个握手成功的页面取得控制权，其他连接收到 `409 Conflict`，
不能发送控制指令；旧连接关闭后，新页面可以重新连接。
握手要求存在 `Host` 头；如果请求带有 `Origin`，它必须与 `http://<Host>` 或 `https://<Host>` 同源。
因此直接访问设备 IP、通过 Caddy 或其他 HTTPS 反向代理访问时都不需要写死域名，但代理必须保留原始 Host。
没有 `Origin` 的非浏览器客户端仍可连接，这不代表身份认证，也不会改变可信局域网边界。
页面关闭时通过 WebSocket 尝试立即停车；指令未送达时，方向控制的 400ms 时长限制仍会清零输出。

遥控页和 WebSocket 没有账号、TLS 或身份认证；单控制者和 Origin 校验只防止多个页面抢控制及跨站页面直接连接，
不能阻止同一可信网络内的其他客户端访问。只应在可信网络中使用。

继电器为 3.3V 单路、触发跳帽设在 L 档（低电平吸合），触点短接发射器的发射按钮，
放电回路在发射器内部不经过任何触点。

线圈与发射器由 5V 降压得到的专用 3.3V 供电，不占用主控 3V3。发射器常供电持续充能，
固件不控制其通断，上电即处于可发射状态。触点极性若与本文不一致，按实物调整 `config.h` 后重新验证。

实物接线、电平、供电、Flash 和 PSRAM 必须核对后才能烧录。
