# PAO 项目板

ESP32-S3，默认 16 MB Flash、八线 PSRAM。使用 Wi-Fi、I2S 数字麦克风
（如 INMP441）、I2S 功放（如 MAX98357A）、BOOT 按键、WS2812 状态灯、MX1508 双路电机驱动
和一块 3.3V 单路继电器组成的发射控制，以及 SSD1306 128×64 I2C OLED。
不需要摄像头或独立音频 Codec。

GPIO 按[硬件接线图](../../../hardware/README.md)配置，具体定义在本目录 `config.h`：

| 模块 | 信号 | GPIO |
| --- | --- | --- |
| I2S 麦克风 | WS / SCK / DIN | 4 / 5 / 6 |
| I2S 功放 | DIN / BCLK / LRC | 7 / 15 / 16 |
| BOOT 按键 | 低电平按下 | 0 |
| WS2812 状态灯 | 数据 | 48 |
| SSD1306 OLED | SDA / SCL | 41 / 42 |
| MX1508 右电机 | IN1 / IN2 | 11 / 12 |
| MX1508 左电机 | IN3 / IN4 | 13 / 14 |
| 继电器 发射 | 低电平吸合 | 18 |

麦克风采样率 16 kHz，扬声器播放采样率 24 kHz。BOOT 单击切换对话，
启动阶段单击进入配网；没有保存的网络时沿用小智配网流程。
唤醒词为“小炮小炮”，也可按键启动对话。乐鑫没有该词的预训练 WakeNet 模型，
固件用 MultiNet（`mn7_cn`）把它作为命令词识别，配置在 `firmware/sdkconfig.defaults`：
`CONFIG_CUSTOM_WAKE_WORD` 为空格分隔的拼音，`CONFIG_CUSTOM_WAKE_WORD_THRESHOLD`（1–99，越小越灵敏）
用于调节误唤醒和漏唤醒，需实机测试后确定。
MultiNet 计算量是 WakeNet 的数倍，固件只在 VAD 判定为语音及其后 1 s 内运行识别，
唤醒词中间的停顿不会打断识别；环境噪声持续触发 VAD 时 CPU 占用会回升。
设备说话或聆听时再次说唤醒词会打断当前回复并重新开始聆听。
直接说话打断需要回声消除，板上 I2S 没有扬声器回采通道，暂不支持。
板型和构建配置名称均为 `pao`，
不复用上游参考板的 OTA 标识。

OLED 的 VCC 接 3V3、GND 接系统地，按模块 SDA/SCL 丝印连接；模块应带 I2C 上拉。
默认地址为 `0x3C`，总线速率 400 kHz。地址、分辨率和显示镜像设置集中在 `config.h`，
若实物地址为 `0x3D` 或画面方向不符，修改对应配置后重新编译。
GPIO41/42 用于屏幕后占用外部 JTAG 引脚，USB GPIO19/20 保留。

屏幕复用小智 OLED 界面，显示设备状态、表情和对话。启动时探测屏幕；
未连接或驱动初始化失败时记录日志、释放已申请的显示资源，并继续以无屏模式运行。
接入后运行期间拔除屏幕不支持自动恢复，需重新连接后重启。

板级初始化创建左右 `Motor`，再创建 `Chassis`，上电保持两轮停止；
随后创建 `Launcher`，上电保持两路继电器断开。
左轮按 `IN4/IN3` 顺序创建 `Motor`，反转左侧安装极性，使两轮正速度均表示车体前进；
右轮仍按 `IN1/IN2` 顺序。更换电机或接线后需重新核对方向。
底盘通过小智的设备 MCP 协议向灵矽暴露两个工具，联网激活后随设备工具列表上报：

- `self.chassis.drive`：`forward`、`turn` 均为必填整数，范围 `[-100, 100]`。
  `forward` 正数前进、负数后退；`turn` 正数左转、负数右转；同时为零立即停止。
  两轮差速：`forward` 为 0 时左右轮以 `turn` 反向转动原地旋转；行驶中转向量随速度减小，
  全速时减半，转弯时内侧轮减速但不停转。
  `duration_ms` 范围 `[100, 15000]`，默认 1000 毫秒，到时自动停止。
  单次超过 15 秒直接返回参数错误，不执行运动，也不自动截短时长。
  返回 `true` 表示已接受指令，新指令替换正在执行的运动。
- `self.chassis.stop`：无参数，立即停止并取消当前定时运动，返回 `true`。

例如“以三成速度前进一秒”对应 `self.chassis.drive` 参数
`{"forward":30,"turn":0,"duration_ms":1000}`；“停止”对应 `self.chassis.stop`。
参数由 MCP 层校验，超出范围或缺少必填参数时返回错误，不执行运动。
速度是占空比，不能据此承诺实际距离或旋转角度。

发射器经设备 MCP 协议暴露 `self.launcher.fire`：无参数，继电器吸合 100 毫秒按下发射按钮后返回 `true`。
发射器常供电自动充能，固件无法得知是否充满，空载充满约 10 s（以模块红灯为准，未经实机校准）；
间隔过短的一发威力不足甚至打空，工具描述提示连续开炮间隔约 10 s。

`self.standby` 无参数，用于“退下吧”“待机”等结束对话的说法：等当前回复播完后关闭对话回到待机，
服务端 3 s 内没有回复时直接关闭，回复超过 20 s 时打断。它不停止底盘。

## 网页遥控

联网后设备在 80 端口提供遥控页，串口日志会打印 `Control page: http://<设备 IP>/`，
同一局域网内用浏览器打开即可。底盘用摇杆控制：推杆量决定目标速度，实际速度按“加速时间”
（默认 1 s，0 为无加速）逐渐升到目标，回拉或反向时快速减速，松手立即停车；也支持 WASD / 方向键。
摇杆按住时每 150 ms 续发一次 400 ms 的运动指令，页面关闭或断网后小车最多再走 400 ms 即停。
开炮键或空格键按一次发射一次。

接口均为 HTTP，参数放在查询串，取值范围与同名 MCP 工具一致，越界返回 400：

- `POST /api/drive?forward=&turn=&duration_ms=`、`POST /api/stop`
- `POST /api/launcher/fire`
- `GET /api/status`：返回 `{}`，供页面检测连接

遥控页没有鉴权，同一网络内的任何人都能控制小车，只应在可信网络中使用。

继电器为 3.3V 单路、触发跳帽设在 L 档（低电平吸合），触点短接发射器的发射按钮，
放电回路在发射器内部不经过任何触点。

线圈与发射器由 5V 降压得到的专用 3.3V 供电，不占用主控 3V3。发射器常供电持续充能，
固件不控制其通断，上电即处于可发射状态。触点极性若与本文不一致，按实物调整 `config.h` 后重新验证。

实物接线、电平、供电、Flash 和 PSRAM 必须核对后才能烧录。
