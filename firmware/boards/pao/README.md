# PAO 项目板

ESP32-S3，默认 16 MB Flash、八线 PSRAM。使用 Wi-Fi、I2S 数字麦克风
（如 INMP441）、I2S 功放（如 MAX98357A）、BOOT 按键、WS2812 状态灯和 MX1508 双路电机驱动。
不需要屏幕、摄像头或独立音频 Codec。

GPIO 按[硬件接线图](../../../hardware/README.md)配置，具体定义在本目录 `config.h`：

| 模块 | 信号 | GPIO |
| --- | --- | --- |
| I2S 麦克风 | WS / SCK / DIN | 4 / 5 / 6 |
| I2S 功放 | DIN / BCLK / LRC | 7 / 15 / 16 |
| BOOT 按键 | 低电平按下 | 0 |
| WS2812 状态灯 | 数据 | 48 |
| MX1508 右电机 | IN1 / IN2 | 11 / 12 |
| MX1508 左电机 | IN3 / IN4 | 13 / 14 |
| 继电器 CH1 充能 | 低电平吸合 | 17 |
| 继电器 CH2 发射 | 低电平吸合 | 18 |

麦克风采样率 16 kHz，扬声器播放采样率 24 kHz。BOOT 单击切换对话，
启动阶段单击进入配网；没有保存的网络时沿用小智配网流程。
默认未启用唤醒词，按键启动对话。板型和构建配置名称均为 `pao`，
不复用上游参考板的 OTA 标识。

板级初始化按上述 GPIO 顺序创建左右 `Motor`，再创建 `Chassis`，上电保持两轮停止；
随后创建 `Launcher`，上电保持两路继电器断开。
实际前进方向需要实机核对，可通过对应 `Motor` 的 GPIO 顺序适配电机接线。
当前尚未接入上层运动指令或发射指令。

两块继电器模块均为 3.3V 单路、触发跳帽设在 L 档（低电平吸合）：CH1 串在高压升压的使能回路上，
CH2 串在 SCR 门极回路，放电回路不经过任何触点。

两路线圈由 3V3 供电，与功放、麦克风和 OLED 共用开发板上的稳压器，需核算 3V3 电流余量；
继电器吸合瞬间的浪涌也应在该余量内。触点极性与本文件不一致时修改 `config.h` 后重新验证。

实物接线、电平、供电、Flash 和 PSRAM 必须核对后才能烧录。
