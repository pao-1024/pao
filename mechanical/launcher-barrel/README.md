# 弹道筒 / 炮筒（发射器改装件）

配套 [issue #61「炮筒改良」](https://github.com/pao-1024/pao/issues/61)。

**安装方式：外扣** —— 直接扣在现有两块木侧板外面，不拆原结构。
筒顶壁高出侧板顶，前口即发射孔，顶部接垂直弹仓实现连续供弹。

## 关键尺寸从哪来

图上标注的 **13 mm 是两块木侧板之间的净距**，也就是弹丸实际跑的通道宽度。
本件是外扣，所以内腔要包住「13 mm 通道 + 两块木板」。

侧向和竖向的余量**分开给**，不能一起放宽：

| 方向 | 余量 | 原因 |
|---|---|---|
| 侧向 | 0.4 mm（紧配） | 落弹孔 12 mm 要落在 13 mm 缝内，两侧各仅 0.5 mm 余量；件在板上一晃孔就偏，纸团会砸在板棱上 |
| 竖向 | 2.0 mm（宽松） | 顶壁悬在侧板上方、不接触板顶，多留余量可吃掉板高误差 |

```
内腔宽 bore_w = 13 + 2×3(板厚) + 2×0.4(侧隙) = 19.8 mm
内腔高 bore_h = 20(侧板高) + 2.0(顶隙)       = 22.0 mm
```

弹仓内径 `mag_d = 12`，**必须小于 13 mm**，否则落弹孔会压到侧板顶面上，
弹丸掉下来会卡在木板边沿。

| 现有木质件 | 值 | 说明 |
|---|---|---|
| `rail_gap` | 13 mm | 两木侧板净距（图上标注，已确认） |
| `rail_t` | 3 mm | 木板厚，按 3mm 胶合板保守估，**未实测** |
| `rail_h` | 20 mm | 侧板高，**未实测** |

木板厚度若实际小于 3 mm，内腔会略松——可以接受，靠安装耳螺钉定位即可；
若明显大于 3 mm，需把 `rail_t` 改大重新导出。

## 结构

```
        ┌──┐          弹仓（垂直，储弹）
        │  │
   ┌────┴──┴────┐
   │            │   ← 筒顶壁（落弹孔贯穿）
   │ ┌────────┐ │   ← 两块木侧板卡在内腔里
   │ │ 13mm缝 │ │
   └─┬────────┬─┘
     │        │      ← 两侧安装耳（4 × Ø2.4 螺钉孔）
```

- **U 型筒身** —— 底面 / 前端 / 后端三面开口，前口即发射孔
- **顶部弹仓** —— 垂直于筒身，与筒身一体，根部带过渡圆角
- **落弹孔** —— 贯穿筒顶壁，正对 13 mm 通道
- **侧向安装耳** —— 4 × Ø2.4 过孔，M2.5 自攻钉固定在底板上

## 生成 STL

STL 是导出产物，不入库（见 `.gitignore`），需要时自行生成：

```sh
# 打印件
openscad --export-format binstl -o barrel.stl barrel.scad

# 剖视图（依赖上一步的 barrel.stl）
openscad -o section.png --viewall --autocenter --imgsize=1100,800 \
  --camera=0,0,0,55,0,25,0 barrel-section.scad
```

用 OpenSCAD 2021 以上版本；2026 nightly 可用 manifold 后端，布尔运算更快。

## 打印

- **方向**：按模型原方向切片，安装耳贴床、开口朝下，**无需支撑**
- 筒顶 19.8 mm 跨桥中间开 12 mm 落弹孔，两侧各留约 4 mm 窄桥
- 建议 0.2 mm 层高、3 层壁、20–30% 填充、开风扇
- PLA 够用，PETG 更耐撞

## 参数化

尺寸分三段：**木质件实测** → **推导内腔** → **打印件参数**。
只改第一段和第三段，第二段自动算。

| 参数 | 含义 | 默认 |
|---|---|---|
| `rail_gap` | 两木侧板净距 | 13 |
| `rail_t` | 木板厚 | 3 |
| `rail_h` | 侧板高 | 20 |
| `clear_side` | 侧向单边间隙（紧配） | 0.4 |
| `clear_top` | 顶壁高出侧板顶（宽松） | 2.0 |
| `bore_w` / `bore_h` | 内腔宽 / 高（自动推导） | 19.8 / 22.0 |
| `barrel_l` | 筒总长 | 70 |
| `wall` | 壁厚 | 2.4 |
| `mag_d` | 弹仓内径（须 < rail_gap） | 12 |
| `mag_h` | 弹仓高出筒顶 | 40 |
| `mag_x` | 弹仓距尾端 | 20 |
| `mount` | 是否要安装耳 | true |
| `screw_x` | 螺钉孔沿筒位置 | [12, 58] |
