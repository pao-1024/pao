# 皮筋储能自动循环发射器（Elastic Launcher）

用**皮筋储能 + 电机自动上弦**替代摩擦轮方案的发射机构。
配套 issue #63，是 `mechanical/launcher-kit`（摩擦轮版）的替代方案。

## 为什么要换掉摩擦轮

原设计复刻卖家结构：单摩擦轮以 9000rpm 甩出弹丸。能量账其实不差，
**差在耦合效率**：

| 方案 | 储能 | 传递效率 | 0.5 g 弹丸初速 |
|---|---|---|---|
| 摩擦轮 9000 rpm | 123 mJ | ~10% | 7.0 m/s |
| 皮筋 ×3 拉伸 22 mm | 58 mJ | ~60% | **11.8 m/s** |

摩擦轮储能更多，但轮缘与弹丸只接触几毫秒、且持续打滑，绝大部分能量变成
摩擦热。皮筋是全程直推，能量几乎不浪费。所以**储能少反而打得快**。

这是"爆发力"的真正来源：不是功率，是**能量释放的时间尺度**。

## 机构链

```
 [电机 130] → [齿轮 1:25] → [小齿轮] ⇄ [齿条] → [滑块+击针]
                                    ↑                    │
                                    │ 走到尽头自然脱开     │ 皮筋拉伸 22mm
                                    └────────────────────┘
                                         皮筋释放 → 击针前冲 → 弹丸出膛
```

关键设计是**齿条走到尽头自动脱扣**：小齿轮驱动齿条把滑块拉到底，
齿条末端离开啮合，滑块被皮筋猛地拽回，击针撞击弹丸。曲柄继续转，
小齿轮重新咬上齿条前端，开始下一轮上弦。**一圈一发，扣住开关就是连发。**

```
       静止位                              上弦位
  ┌──────────┐                        ┌──────────┐
  │ 滑块 ▤▤▤ │→ 皮筋 ←──────────      │▤▤▤ 滑块  │
  └────┬─────┘                        └────┬─────┘
       │击针                              │
   ════╪════ 弹道筒                     ════╪════
      (○) 弹丸
```

## 能量与初速

| 项 | 值 |
|---|---|
| 皮筋 | 3 根并联，单根 k = 80 N/m |
| 拉伸量 | 22 mm（= 击发行程） |
| 储能 | 58 mJ |
| 传递效率 | ~60%（直推，含皮筋内耗与摩擦） |
| 0.5 g 弹丸初速 | **约 11.8 m/s** |
| 0.8 g 弹丸初速 | 约 9.3 m/s |

对比摩擦轮版 7.0 m/s，提升约 1.7 倍。

## 传动

| 项 | 值 |
|---|---|
| 减速比 | 1:25（两级，各 z=10 → z=50） |
| 模数 / 压力角 | m=1 / 20° |
| 中心距 | 30 mm |
| 输出转速 | 9000 ÷ 25 = 360 rpm |
| 理论射速 | 6 发/秒（带载实际约 2~4 发/秒） |

齿轮层在 Y 方向错开（15mm / 23mm），避免两个 z=50 齿轮互相干涉。

## 生成 STL

```sh
for p in base-plate barrel striker gearbox band-frame button-mount gear-z10 gear-z50; do
  openscad --export-format binstl -o "$p.stl" "$p.scad"
done
python meshcheck.py          # 校验封闭性/体积/包围盒
```

## 齿轮实现说明

`gearlib.scad` 用的是**梯形齿廓 + 3D 布尔并集**，不是渐开线。

原因是渐开线齿廓拼成单一闭合多边形时，齿根圆弧与相邻齿面在端点重合，
OpenSCAD 的 2D 三角化会产生自交面，挤出后网格不封闭（实测两份齿轮都是
非流形）。改成「根圆柱 + 内嵌齿块」后体积重叠而非面接触，稳定输出封闭网格。

梯形齿对 3D 打印的低速轻载玩具足够；齿侧留 0.15 mm 齿隙防止装配咬死。

## 待验证

- **未做实体打印、未做整机装配、未做实弹测试**
- 齿型脱扣后的**再咬合时序**是最不确定的部分：皮筋把滑块弹回后，
  小齿轮必须正好转到能重新咬上齿条的位置。实际可能需要加导引斜面
  或在齿条前端做倒角
- 皮筋刚度、根数需按实物试；`band_k = 80 N/m` 是估算
- 电机带载会明显掉速，实际射速低于理论值
- 该机构对打印精度敏感，轴孔配合建议先打样试装
